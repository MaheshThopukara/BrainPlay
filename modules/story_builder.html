ABC Order

Ages 3–8 3 min Easy

Letters — and later, words — arrive scrambled. Pick them in alphabetical order, earliest first.

Builds

  • 🅰️ Alphabet mastery
  • 📖 Dictionary order
  • 🧠 Working memory
  • ⚡ Quick recall

How to play

  1. Scan the tiles
  2. Find the earliest one
  3. Press OK to place it
  4. Repeat in order
  5. Get them all for more ⭐!
Did you know? The alphabet has 26 letters in English.

Rhyme Time

Ages 3–8 3 min Easy

Every round is a different rhyming game: find the rhyme, spot the real one, finish a rhyme, or swap a sound. Words that share an ending win stars.

Builds

  • 🎵 Sound awareness
  • 👂 Listening skills
  • 📖 Early reading
  • 🧠 Phonological skill

How to play

  1. Read or hear each round's question
  2. Some rounds pick one rhyme, some tap a few
  3. D-pad through the chips
  4. Press OK (or Done for many)
  5. Match the ending sound to win stars!
Did you know? Rhymes help your brain remember words 2× longer.
