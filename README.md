# BrainPlay — site

Marketing site for **BrainPlay**, a learning arcade for Android TV, phones, tablets and foldables.

Live at <https://maheshthopukara.github.io/BrainPlay/>

## How this is built

Every page is generated by `tools/site/build_site.py` in the app's repository, from the app itself —
nothing is hand-written here:

- worlds, names and one-line descriptions come from `GameCatalog.kt`
- about / skills / how-to-play / fun facts / ages come from `GameIntros*.kt`, in both the TV-remote
  and the touch wording the app itself shows
- the 151 TV screenshots are captured off a TV emulator at 1920x1080 @ 320dpi, which is the same
  960x540dp logical viewport the television uses
- the 151 phone screenshots are captured upright off a 1080x2340 phone emulator
- the device pictures come from the app's multi-device layout review (phone, tablet, foldable, TV)

Regenerate rather than editing the HTML by hand — hand edits are lost on the next run.
